Informativa sulla Privacy e Architettura Dati

Ultimo aggiornamento: 6 Novembre 2026

Controllo Esclusivo dell'Utente: Fidelity Wallet è un'applicazione Local-First / Offline-First[cite: 2, 3]. Nessun dato personale o contenuto memorizzato viene trattenuto, utilizzato, tracciato o visionato da noi o da terzi[cite: 2, 3]. Tutte le informazioni risiedono ed esistono esclusivamente nelle mani dell'utente finale.

Nessun Server

Le carte fedeltà, i codici e le immagini non lasciano mai il tuo dispositivo. Nessun database remoto[cite: 2, 3].

Zero Inserzioni / Telemetria

Nessuna profilazione commerciale, nessun tracciamento del comportamento o cookie analitici[cite: 2, 3].

Backup Sovrani

I salvataggi delle carte sono gestiti e conservati unicamente dall'utente dove desidera[cite: 2, 3].

1. Raccolta, Archiviazione e Visione dei Dati

Fidelity Wallet opera interamente in ambiente locale sul tuo dispositivo[cite: 2, 3]:

  • Nessun Trattenimento o Visione: Non raccogliamo, non memorizziamo, non usiamo e non possiamo visionare alcuna carta fedeltà, codice a barre, nota o immagine inserita[cite: 2, 3].
  • Archiviazione Locale: Tutti i dati relativi alle tue carte vengono salvati esclusivamente nella memoria locale del tuo browser/dispositivo (tramite tecnologie quali localStorage o IndexedDB)[cite: 2, 3].
  • Nessuna Trasmissione Remota: L'applicazione non invia alcuna informazione a server gestiti dagli sviluppatori o a terze parti[cite: 2, 3].

2. Permessi del Dispositivo

Per offrire funzionalità avanzate in totale riservatezza, l'applicazione può richiedere permessi specifici[cite: 2, 3]:

  • Fotocamera: Utilizzata esclusivamente sul dispositivo per la scansione istantanea dei codici a barre o QR code delle carte[cite: 2, 3]. L'immagine non viene salvata esternamente né trasmessa[cite: 2, 3].
  • Geolocalizzazione: Utilizzata localmente per ordinare o suggerire le carte pertinenti quando ti trovi nei pressi dei punti vendita[cite: 2, 3]. Nessun dato sulla posizione abbandona mai il tuo dispositivo[cite: 2, 3].

3. Backup e Trasferimento Dati

Qualsiasi operazione di backup o ripristino delle carte è sotto il controllo diretto ed esclusivo dell'utente[cite: 2, 3]:

  • I file di esportazione/backup vengono generati ed elaborati unicamente sul tuo hardware[cite: 2, 3].
  • Non forniamo né gestiamo server di sincronizzazione o cloud proprietari[cite: 2, 3].

4. Cookie, Tracciamento e Hosting

L'applicazione non utilizza cookie di profilazione o strumenti di analisi di terze parti[cite: 2, 3].

L'applicazione è distribuita tramite GitHub Pages[cite: 2, 3]. Il servizio di hosting può raccogliere log di rete standard (es. indirizzi IP) a fini di sicurezza e operatività infrastrutturale[cite: 2, 3]. Per maggiori informazioni, puoi consultare la GitHub Privacy Statement[cite: 2, 3].

5. Modifiche alla Privacy Policy

Ci riserviamo il diritto di aggiornare questa informativa in qualsiasi momento[cite: 2, 3]. Eventuali modifiche saranno pubblicate direttamente su questa pagina[cite: 2, 3].

6. Contatti

Per chiarimenti relativi all'architettura o a questa informativa, è possibile aprire una segnalazione (issue) direttamente sul repository GitHub del progetto[cite: 2, 3].
