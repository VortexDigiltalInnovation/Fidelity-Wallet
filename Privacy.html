Informativa sulla Privacy

Ultimo aggiornamento: 6 Novembre 2026

L'applicazione Fidelity Wallet è progettata per rispettare appieno la privacy degli utenti.

1. Raccolta e Archiviazione dei Dati

Fidelity Wallet funziona principalmente come applicazione offline-first o locale. Tutti i dati relativi alle carte fedeltà, codici a barre, immagini e note vengono salvati esclusivamente sul dispositivo dell'utente tramite le tecnologie di archiviazione locale del browser (es. localStorage o IndexedDB).

Nessun dato personale o contenuto memorizzato nell'applicazione viene trasmesso, tracciato o salvato su server esterni o di terze parti gestiti dallo sviluppatore.

2. Permessi del Dispositivo

L'applicazione potrebbe richiedere l'accesso a determinate funzionalità del dispositivo (ad esempio la fotocamera per la scansione dei codici a barre o la geolocalizzazione per mostrare le carte pertinenti in base alla posizione). Tali permessi vengono utilizzati unicamente all'interno del dispositivo per fornire le funzionalità richieste e non per raccogliere o tracciare informazioni all'esterno.

3. Cookie e Tracciamento

L'applicazione non utilizza cookie di profilazione, cookie di terze parti o strumenti di tracciamento analitico/pubblicitario.

4. Servizi di Terze Parti

L'applicazione è ospitata tramite GitHub Pages. Il servizio di hosting di GitHub potrebbe raccogliere log di rete standard (come indirizzi IP) per motivi di sicurezza e operatività del servizio web. Per maggiori dettagli, fare riferimento alla GitHub Privacy Statement.

5. Modifiche a questa Privacy Policy

Ci riserviamo il diritto di aggiornare questa informativa in qualsiasi momento. Eventuali modifiche saranno pubblicate direttamente su questa pagina.

6. Contatti

Per domande o chiarimenti relativi a questa informativa sulla privacy, è possibile aprire una segnalazione (issue) direttamente sul repository GitHub del progetto.
